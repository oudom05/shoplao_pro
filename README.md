🛠️ ແນວທາງການອອກແບບ Data Structure (ສຳລັບເອົາໄປຕໍ່ຍອດໃນ Flutter / Database)
ເມື່ອເຖິງເວລາຕ້ອງເຊື່ອມ Database ຫຼື API ໂຄງสร้างຂໍ້ມູນ (Model) ຂອງ Pre-order ຈະມີลักษณะປະມານນີ້:

ຕາຕະລາງ / ໂຄງສ້າງ Lot (ລັອດສິນຄ້າ):

lotId: ID ຂອງລັອດ (ເຊັ່ນ: LOT-2026-001)

lotName: ຊື່ລັອດ (ເຊັ່ນ: ລັອດວັນທີ 10 ສິງຫາ)

startDate: ວັນທີເລີ່ມເປີດຮັບ

closingDate: ວັນທີປິດຮັບ (ຕົວຢ່າງ: ວັນທີ 10)

deliveryWeeks: จำนวนອາທິດທີ່ໃຊ້ຂົນສົ່ງ (ຕົວຢ່າງ: 2 ອາທິດ)

status: ສະຖານະ (ເປີດຮັບ / ປິດຮັບ / กำລັງຂົນສົ່ງ / ສິນຄ້າຮອດແລ້ວ)

ຕາຕະລາງ / ໂຄງສ້າງ Product in Lot (ສິນຄ້າໃນລັອດນั้นໆ):

productId: ID ສິນຄ້າ

lotId: ຜูกກັບລັອດໃດ

name: ຊື່ສິນຄ້າ

costPrice: ລາຄາຕົ້ນທຶນ

sellingPrice: ລາຄາຂາຍ

unit: ໜ່ວຍນັບ (ຜືນ, ອັນ, ໂຕ...)

isClothing: boolean (true/false) -> ຖ້າເປັນ true ໃຫ້ມີ field sizes (ເຊັ່ນ: S=5, M=10)

            (Order Management System) ສຳລັບຮ້ານຄ້າ ເຊິ່ງມີຄວາມສາມາດ ແລະ ຟັງຊັນການເຮັດວຽກຫຼັກໆ ດັ່ງນີ້:

            ຮອງຮັບການສ້າງອໍເດີ້ 2 ປະເພດ:

            ອໍເດີ້ພ້ອມສົ່ງ (Ready): ສຳລັບສິນຄ້າທີ່ມີຢູ່ໃນຄັງພ້ອມສົ່ງເລີຍ.

            ອໍເດີ້ Pre-order: ສຳລັບສິນຄ້າທີ່ຕ້ອງຈອງລ່ວງໜ້າ ຜ່ານລະບົບລັອດ.

            ລະບົບຈັດການລັອດ Pre-order ທີ່ສະຫຼາດ:

            ກັ່ນຕອງລັອດອັດຕະໂນມັດ (_activeLots): ກວດສອບວັນທີປິດຮັບອໍເດີ້ທຽບກັບວັນທີປັດຈຸບັນ (DateTime.now()) ຖ້າລັອດໃດໝົດອາຍຸ/ກາຍວັນທີແລ້ວ ມັນຈະຖືກເຊື່ອງອອກຈາກ Dropdown ໂດຍອັດຕະໂນມັດເພື່ອປ້ອງກັນການເລືອກຜິດ.

            ສ້າງລັອດໃໝ່ພ້ອມເລືອກວັນທີ: ມີປຸ່ມກົດເປີດ Popup ພ້ອມກັບ CupertinoDatePicker ເພື່ອໃຫ້ສາມາດກຳນົດຊື່ລັອດ ແລະ ວັນທີປິດຮັບໄດ້ຢ່າງສະດວກ.

            ລະບົບເລືອກສິນຄ້າຈາກຄັງ (_inventoryProducts):

            ມີ Modal Bottom Sheet ໃຫ້ກົດເລືອກສິນຄ້າຈາກຄັງສິນຄ້າ ເຊິ່ງຈະດຶງຂໍ້ມູນຊື່, ລາຄາ ແລະ ຈຳນວນຄົງເຫຼືອມາສະແດງ.

            ລະບົບຄຳນວນເງິນມັດຈຳອັດຕະໂນມັດ:

            ສຳລັບອໍເດີ້ Pre-order ສາມາດເລືອກຮູບແບບການຈ່າຍເງິນໄດ້ທັງ ມັດຈຳ 30%, ມັດຈຳ 50% ຫຼື ຈ່າຍເຕັມ 100% ໂດຍລະບົບຈະຄຳນວນຍອດເງິນອອກມາເປັນຕົວເລກທີ່ຈັດຮູບແບບ (Format) ເງິນກີບໃຫ້ໂດຍອັດຕະໂນມັດ.

            ກວດສອບຄວາມຖືກຕ້ອງຂອງຂໍ້ມູນ (Validation):

            ກວດສອບເບີໂທ WhatsApp ວ່າຖືກຕ້ອງຕາມກຳນົດ ຫຼື ບໍ່ (ຕ້ອງມີຢ່າງໜ້ອຍ 8 ຫຼັກ).

            ກວດສອບວ່າໄດ້ເລືອກສິນຄ້າ, ປ້ອນຊື່ລູກຄ້າ ແລະ ເລືອກລັອດ Pre-order ແລ້ວຫຼືຍັງ ກ่อนທີ່ຈະກົດບັນທຶກ.

            ສະແດງລາຍການອໍເດີ້ຫຼ້າສຸດ ແລະ ເຊື່ອມຕໍ່ໄປໜ້າອື່ນ:

            ສະແດງລາຍການອໍເດີ້ທີ່ຖືກບັນທຶກໃໝ່ລົງໃນ List ແບບ Real-time (ສະແດງຜົນສູງສຸດ 3 ລາຍການຫຼ້າສຸດ).

            ມີປຸ່ມ "ເບິ່ງທັງໝົດ >" ທີ່ສາມາດກົດເພື່ອພາຜູ້ໃຊ້ໄປສູ່ໜ້າລວມອໍເດີ້ທັງໝົດ (AllOrdersView) ໄດ້.
